# Collar app firmware (Phase 2): behavior recognition on the chip

Runs the int8 CNN on the XIAO nRF52840 Sense with TensorFlow Lite Micro and prints the
recognized behavior once per second over the USB serial port. Phase 3 will store the
per-minute summary (contract 4.7) in flash and add BLE sync and OTA.

```
IMU 50 Hz → ring buffer (last 2 s) → every 1 s: int8 preprocessing → CNN → smoothing → log
```

- **Model:** `src/model/` is generated by `ml/scripts/export_model.py` from
  `ml/models/cnn_multi_int8.tflite` (87 dogs; classes still, walking, running, shaking;
  18.9 KB). The generated `model_config.h` carries the class IDs, quantization, the training
  input scale and the exact operator list, so firmware and training cannot drift apart.
- **Preprocessing** (`src/preprocess.c`): raw int16 → g / dps → 7 channels with |a| →
  training scale → int8. Host-tested against the Python training path.
- **Smoothing** (`src/smoothing.c`, ADR 0002): majority of the last 5 windows for states;
  shaking shows up after 1 window ≥ 0.6, scratching after 2. Host-tested.
- **Inference** (`src/model_runner.cc`): TFLite Micro with Arm CMSIS-NN kernels
  (`arm_convolve_1_x_n_s8` and friends), 16 KB tensor arena (boot log prints how much is used).

## Build

The TFLite Micro module is optional in NCS and not part of a default install. Fetch it once,
next to the SDK (the commit is the one NCS v2.9.0's Zephyr expects):

```bash
mkdir -p /c/ncs/extra && cd /c/ncs/extra
git clone --filter=blob:none https://github.com/zephyrproject-rtos/tflite-micro.git
cd tflite-micro && git checkout 48613f7ba1ffbda46ad771a77a35408f48f922e9
```

Then build like the logger, adding the module path:

```bash
cd /c/ncs/v2.9.0
APP=C:/Users/<you>/Documents/projetos/coleira-inteligente/firmware/app
~/.local/bin/nrfutil.exe sdk-manager toolchain launch --ncs-version v2.9.0 -- \
  west build -p always -b xiao_ble/nrf52840/sense -d C:/ncs/b/app "$APP" \
  -- -DZEPHYR_EXTRA_MODULES=C:/ncs/extra/tflite-micro
```

Flash `C:/ncs/b/app/app/zephyr/zephyr.uf2` the same way as the logger (double-tap reset,
copy to the `XIAO-SENSE` drive).

## Updating the model

```bash
cd ml
uv run python scripts/export_model.py --model models/<new>.tflite --classes 0,1,2,3,4
uv run pytest tests/test_firmware_host.py      # firmware ↔ training consistency
```

Then rebuild. If the boot log says the model init failed, raise
`CONFIG_COLLAR_TENSOR_ARENA_SIZE` in `prj.conf`.
